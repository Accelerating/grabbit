# 当前实现状态（2026-09-17）

## 已实现

- Python 3.13 后端、锁文件、Alembic 增量迁移、管理员 CLI、Argon2id 登录/会话/CSRF/改密、设置 API。
- React SPA、登录壳、双语与主题、普通下载页面；前端静态包随 FastAPI 同源提供。
- 普通下载和视频下载的“新建任务”在列表页以可关闭弹窗呈现；旧新建页地址转向弹窗地址。前端已接入 shadcn/ui（Radix 底层），两条新建流程使用统一的 Dialog、Card、Field、Input、Textarea、Checkbox、Button 组件，不再依赖旧表单的全局输入框样式；列表和窄屏排版也已调整字号与长文本换行。
- 普通 HTTP/HTTPS 任务创建、重复提示、幂等键、持久队列、排序版本校验、暂停/继续/取消/重试接口。
- 应用专用 aria2 进程与本机 RPC 适配器；调度器默认全局并发 1，稳定 GID 先入库后启动，完成后索引实际产物；磁盘不足持久阻断。
- 基本任务/历史/队列 API，普通下载列表通过 SSE 触发 REST 刷新，并以较低频率轮询兜底。
- 种子文件限额上传、安全解析、私有原件保存、文件候选分页；可选文件创建持久任务并经 aria2 的 `addTorrent` 下载。
- SSE 后端事件流：有界重放、快照、心跳和会话撤销断连；任务和队列变动发布事件。
- 磁力链接可创建元数据队列项；aria2 以 metadata-only 模式获取种子元数据，完成后等待用户选文件，确认后才排内容下载。前端单连接 SSE 接收变化并刷新 REST 列表，断线时回退定时刷新。
- 文件浏览、受认证的文件下载与 Range；历史和文件页面接入真实 API。调度器重启后可按已有 GID 尝试重新接管任务；aria2 子进程意外退出后会以有界间隔重启并重新对账。
- Cookie 配置后端与独立页面：新增配置采用 shadcn 弹窗，支持 Netscape cookies.txt 上传或粘贴、域名范围检查、私有版本化存储、站点默认、名称/域名编辑、内容替换，以及活动任务引用时阻止删除。数据库表间引用由应用层维护，不使用数据库外键约束。
- 视频下载增量：YouTube/B站网址和 Cookie 站点匹配校验；持久化异步分析作业在服务重启后重新排队，可取消运行中的解析，结果保留 24 小时后过期清空；前端轮询并在同一浏览器会话刷新后恢复最近一次分析。独立 yt-dlp 子进程预解析有 120 秒超时与 4 MiB 输出上限；合集使用扁平逐条输出与最多 100 条的页面，只保存轻量条目摘要，前端可分页勾选最多 500 个条目，按统一策略创建独立视频任务并关联分组。单视频可按视频／仅音频策略创建任务。视频与普通下载共用持久队列和默认并发 1，执行时创建 0600 Cookie 快照、可停止并按任务目录索引产物，ffprobe 确认有音视频流才标记完成。视频下载后可按解析结果选择字幕语言并转换为 VTT，失败只记警告；历史页支持排队单独重试字幕而不重下主媒体。旧同步解析接口仍保留兼容。
- 独立播放器已用受认证的 Range 文件接口接入浏览器原生音视频控件和关联 WebVTT 字幕；打开播放器时可按需排队 ffprobe，缓存并显示时长、封装、音视频编码与分辨率，文件变化后失效，浏览器实际播放失败时提供下载提示。历史页支持先预览再删除终态记录，磁盘文件及文件索引保留。文件页支持在受控下载根目录下新建单层目录；文件删除支持最多 100 个文件的多选、签名的 5 分钟预览和持久作业，逐项记录结果并在重启后续跑；执行前复核文件版本与任务占用。目录删除也先预览文件数、目录数与总大小，拒绝活动任务占用、符号链接和超过 100 个条目的目录，确认后复用持久作业，执行时仅删除预览过的文件并逐层移除空目录。
- 设置页显示 aria2、yt-dlp、ffmpeg、ffprobe、Deno 的版本/可用性检测；Debian 13 且装好受限 helper 时可提交 aria2 / ffmpeg 的持久安装作业。后端暂停新任务派发、等现有任务结束、检查可用内存与磁盘，再以固定 sudo 命令调用 helper；结果与最多 64 KiB 日志持久保存。其他系统仅检测。
- 运维 CLI 新增 SQLite 在线一致性备份、私有状态及可选环境文件备份（不默认包含下载媒体），以及路径、库完整性和本机工具的 `doctor` 自检。部署目录提供只接受 `aria2` / `ffmpeg` 两种固定动作的 Debian 13 root helper 与精确 sudoers 模板。
- 提供 Debian 目标机测量脚本，可按秒记录整个 systemd 服务 cgroup 的内存、峰值、OOM、进程数和 localhost 健康检查延迟，供 768 MB 空闲/典型任务验收使用。

## 已验证

- 后端常规 pytest、Python 3.13.3 导入与迁移、前端类型检查和 SPA 生产构建；本次迁移已在现有本地开发数据库升级。前端有使用模拟 API 的无头 Chrome 排版检查，覆盖 1440px 和 390px 下的文件页、Cookie/下载弹窗以及下载、视频、历史页共用栏位；不替代真实账号下的端到端验收。
- 本轮后端 38 通过、8 个真实 aria2 测试跳过；前端类型检查、生产包和无头浏览器排版检查通过（含安装区域的桌面／手机宽度）。备份测试验证 SQLite 内容、私有文件、环境文件、权限及排除下载媒体；安装作业以模拟 helper 验证，Debian 主机已通过 sudoers 规则验证但尚未从网页实际触发 apt 作业。
- 已在一台 Debian 13 amd64、715 MiB RAM + 768 MiB swap 的 VPS 首次部署 Caddy + Grabbit；GitHub 拉取、锁定依赖安装、全部迁移、systemd 启停、HTTPS、管理员登录、鉴权依赖检测和 30 秒空闲 cgroup 测量通过，细节见 [部署记录](./deployment-report.md)。这不等于典型任务 768 MiB 验收。
- aria2 1.37.0 在开发机上的本地 HTTP 真实下载，以及支持 Range 的来源暂停/继续。
- aria2 1.37.0 + 本地 seeder/HTTP tracker：真实磁力元数据获取、暂停后的用户选择边界、按选定文件完成内容下载，完成后上传速率归零；调度器的选文件状态机另有模拟测试。
- 本地 peer 驱动的应用层完整链路：登录并经 API 创建磁力任务、获取元数据、选文件、队列调度、文件索引/下载与历史查询；随后上传种子经 API 创建任务并完成真实下载。内部元数据文件不会出现在文件浏览中。
- 真实 HTTP 下载途中杀掉应用专用 aria2 子进程，调度器自动重启引擎、重新对账并从部分文件恢复到正确产物。
- 两个真实 HTTP 任务按默认并发 1 串行执行，第二个任务在首个占槽期间未被送入引擎；支持与不支持 Range 的来源均通过中途进程退出恢复测试。
- 未安装 aria2 时 Web 可启动，下载任务保持等待；深链可刷新，未知 API/缺失 asset 返回 404。

## 尚未完成或未验收

- 磁力与种子的应用层本地 peer 端到端测试、真实 HTTP 串行执行和引擎崩溃恢复（含非 Range 来源）已通过；服务整体重启故障注入、低内存/磁盘保护验收仍未完成，不能称作阶段 1 完整验收。
- SSE 已有浏览器单连接、带抖动的有界指数退避、cursor 重放和 REST 重取，但浏览器断网/跨重启事件乱序对账尚未专项验收；完整文件索引与跨浏览器播放能力验证仍待实现。文件与目录删除作业已有基础实现，但大目录分页预览及目标系统故障注入尚未验收。
- Cookie 管理界面、视频任务引用和执行快照已接入，未运行任务可更换 Cookie 后重试；视频执行接入 yt-dlp 结构化进度，优先展示当前流字节、可靠或估算总量、百分比、速度与剩余时间，缺数据时退回落盘字节估计；不会把当前流百分比当成任务总进度。字幕选择、单独重试、分析取消／过期和合集分页入队已有基础实现，仍需 YouTube 播放列表及 B站多 P 真实站点验收；本次无 Cookie 的 B站解析被站点 HTTP 412 拒绝，工作区中已无先前的 Cookie 文件。网页安装实际作业、可重复的自动首次部署流程与 768 MiB 典型任务实机测量仍待完成。目录删除的更大规模分页预览与目标系统验收尚未完成。
- 真实下载引擎的既有验收在 macOS 开发机上完成；Debian 主机目前只完成依赖可用性、HTTPS 登录和空闲测量，不等于 Debian 下载链路或 768 MiB 典型任务验收。
- `doctor` 目前是基础路径/SQLite/可执行文件自检，不含 aria2 RPC、Deno/EJS 自检。网页安装的 Debian 实机验证、yt-dlp/Deno 的受控版本环境和回滚、首次部署自动化仍未完成。
